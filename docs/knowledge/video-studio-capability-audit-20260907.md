## 今回の限定実生成テスト

- 目的：合成の白いカップと湯気で、物体形状・自然な動き・カメラ安定性を確認する。実在商品の証拠ではない。
- プロジェクト：`studio-canary-20260907`。最初は640×360、49/24秒のネイティブ素材。1080pや大手サービス同等品質とは表示しない。
- 検証用インスタンス：`50127927`。開始時は既存インスタンス0台を確認。複数契約への自動リトライなし。
- 計算単価：約$0.13556/時。別途ストレージ・転送。最初の検証枠は最大$3を目安とし、自動チャージや追加購入はしない。
- 20分で初期化を打ち切り、生成待ちは240秒。成功／失敗の後、当該検証用インスタンスだけを停止・削除し、残存チェックを行う。素材は先にHetznerへ保存する。
- 実課金の厳密なハードキャップではなく、単価と実行時間を制限した単発テスト。残高差と請求反映は実行後に確認する。
- `source-test-manifest.json`と`source-test-result.json`は永続ワークスペース側の成果物。コードリポジトリへメディアや秘密情報を入れない。
- 人による下書き・最終承認、公開、顧客課金は未実施。

## 実生成・品質評価

### 今回の実測結果

- 実生成成功。認証付きComfyUIAdapter経由、doctorの本番準備検査とモデルSHA照合を通過。生成処理34.009秒、契約から削除確認まで863秒。初回イメージ展開・モデル取得等が大半を占める。
- MP4実測：640×360、24fps、2.041667秒、55,213 bytes、H.264。AACトラックはあるが音量最大-91dBで実質無音。音声生成成功として数えない。
- 素材：Hetzner永続領域 `/data/video-factory/projects/studio-canary-20260907/scenes/raw/default/001-shot-001.mp4`。ローカルコピーは `/Users/apple/Desktop/Paradigm-video-QA-20260907/studio-canary-20260907-export/scenes/raw/default/001-shot-001.mp4`。
- 4枚の時系列フレームによる目視：白いカップの本体・取手はおおむね一貫、背景も安定。湯気は弱く、指定した緩い前進が明瞭ではない。柔らかい質感と窓の白飛びがあり、高級商品広告の品質合格にはしない。全フレームの時間的一貫性、人の品質承認は未確認。
- GPU `50127927` は停止後に削除。APIの削除後一覧とChromeのInstances (0)で残存なしを確認。削除したのは今回作成した一時GPUのストレージのみ。生成物は先にHetznerへ保存済み。
- Chrome残高は開始$11.53→終了時点$11.49。表示差$0.04は暫定であり、転送・遅延計上を含む確定請求額や1本単価ではない。自動チャージ操作なし。
- 判断：T2V素材1本の疎通と終了後解放は現在成功。高解像度・長尺・音声/口形・I2V・複数本バッチ・障害時の自動解放は未実証。HeyGen/Runway/Kling/Seedanceと同等という主張は不可。

### 次の改善順序

1. 今回の実物を所有者が確認し、動き・質感の不足を評価する。下書き/最終承認は代行しない。
2. 5〜10秒・720p以上の候補ワークフローを作り、モデル/ワークフローの権利・SHA承認を維持して複数seedで比較する。現在の固定49フレーム定義を無断で置き換えない。
3. プリウォーム済み構成やモデルキャッシュの費用を比較する。常駐GPUを無期限に置く判断はせず、起動費込みの採用秒単価を測る。
4. PR #740の台帳から実ジョブの排他・コールバック・GPU停止確認まで接続し、再送/停止失敗/再起動試験後に正式リリースを通す。

## 量産可否の判定条件（まだ未達）

1. 用途ごとの実物：商品B-roll、人物・会話、画像からの動画、説明動画を別々に評価する。
2. 代表的な5〜10秒以上の素材を複数本作り、解像度・音声有無・設定を明示する。単一の2秒素材で量産可能と判断しない。
3. 人物や商品の同一性、破綻、指示への一致、動き、音声・口形、編集の各軸を記録する。
4. 成功率、生成時間、採用できた1秒当たり費用、失敗費用を計測する。
5. 再送の二重課金防止、停止失敗時の対応、再起動後の設定復元、モデルの固定、成果物の永続保存を検証する。
6. 所有者が下書きと最終成果物を確認してから、合格した用途だけ量産へ進める。

## 今回見つかった運用不具合

Vastテンプレート検索で`order_by=count_created`を付けるとHTTP 400。保存済みhash_idの検索で、select_cols単独は200、order_by単独は400と切り分けた。検索コードから当該パラメータを除き、ローカルで並べ替える修正とモック回帰検査を追加。公式ドキュメントには当該パラメータが残っているため、実測に基づく互換修正として扱う。
