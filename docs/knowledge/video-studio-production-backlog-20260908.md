## P01：45秒人物実写作品の制作設計

仮題「朝の余白」。既存Morning Breathと同じ架空の成人女性・陶芸工房を継承する。
想定用途はオリジナルのライフスタイル短編。実在ブランド、効能、本人の発言を示す広告にはしない。
主納品は16:9、45秒、日本語、音声付きMP4。縦型派生は横型承認後に独立した構図審査を行う。
高解像度への拡大で解剖・動作の不具合を隠さず、元映像を先に検査する。

| 尺 | 画/出来事 | 検査の焦点 |
|---|---|---|
| 0–6秒 | 女性が窓際の机に腰掛ける導入 | 歩行/着座、腕と机の遮蔽、身体の比率 |
| 6–12秒 | 器を机に置く手元 | 指の本数、接触、器の剛性、影 |
| 12–19秒 | 顔の中景、呼吸が静まる | 顔の同一性、肌、自然な瞬き |
| 19–25秒 | 同じ部屋の窓と作業道具 | 空間、光源、小物の配置連続性 |
| 25–32秒 | 器を手に取り、窓に視線を向ける | 前後の手/器の位置、視線、動作の意図 |
| 32–42秒 | 作業に戻る、短編としての結末 | 別角度でも同一人物、手の接触、目的のある動き |
| 42–45秒 | タイトルと合成映像/音声クレジット | 読める表示、誤認のない表記 |

ナレーション案: 「急ぐ朝にも、自分の速さがある。手のひらに触れる器。窓から差す光。ひと息おいて、今日の一つを始めよう。」
発話時間を先に測定し、台詞の末尾切れや尺の水増しをしない。
静止尾部、同じ素材のループ、長い終了カードで45秒に見せることは禁止。
