technologiesカラム：JSON配列で技術名・カテゴリ・バージョンが格納されている
Shopify使用サイト抽出クエリ（月1TB無料枠内）
SELECT
  url,
  -- 国判定（TLDから）
  REGEXP_EXTRACT(url, r'\.(co\.uk|com\.au|de|fr|ae)/') AS country_tld,
  tech.technology AS tech_name
FROM
  `httparchive.all.pages`,
  UNNEST(technologies) AS tech
WHERE
  date = '2024-06-01'
  AND tech.technology = 'Shopify'
LIMIT 50000
対応している主な技術（抽出可能）

セットアップ手順（5ステップ）
Step 1
Googleアカウントで console.cloud.google.com/bigquery にアクセス
Step 2
新規プロジェクトを作成（無料）
Step 3
左サイドバー「+ Add」→「Star a project by name」→ httparchive と入力
Step 4
上記のSQLをエディタに貼り付けてRUN
Step 5
結果をCSVでエクスポート（最大1GB無料）
注意点
クロール対象
上位100万サイト（CrUXレポート基準）。零細SMBは含まれない場合あり
更新頻度
月次（毎月新しいdateが追加される）
コスト注意
フルスキャンは30TB処理 = $150。必ずLIMITと日付絞り込みを入れること
