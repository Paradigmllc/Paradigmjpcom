③ HTTP Archive BigQuery — 本命 最強

HTTP ArchiveはWappalyzerのフォーク版で技術検出を行っており、月次クロールデータをBigQueryで公開。実質的な「PublicWWWの無料OSS版」。月1TBまで無料なのでこのクエリは実質無料。

-- WordPress使用サイト一覧を無料取得
SELECT
  url,
  technologies
FROM `httparchive.all.pages`
WHERE date = '2024-06-01'
  AND LOWER(technologies) LIKE '%wordpress%'
LIMIT 50000
技術BigQueryクエリ例用途
WordPressLIKE '%wordpress%'WP案件・ブログリニューアル
WooCommerceLIKE '%woocommerce%'EC移行ターゲット
ShopifyLIKE '%shopify%'ShopifyストアDB（Kaggleと相互補完）
SquarespaceLIKE '%squarespace%'デザイン重視サイト
WebflowLIKE '%webflow%'デザイナー系ターゲット
WixLIKE '%wix%'中小企業・個人事業主
