Crawl4AI — コンタクトフォーム自動検出
ライブラリ
Crawl4AI（Python・Playwright バックエンド・非同期クローラー）
主な用途
リストのドメインから問い合わせフォームURLを自動抽出→Playwright自動送信へのパイプライン
コスト
完全無料（OSS）サーバー費用のみ
インストール
pip install crawl4ai && playwright install chromium

基本実装 — フォームURL検出
import asyncio
from crawl4ai import AsyncWebCrawler

async def find_contact_form(url: str):
    async with AsyncWebCrawler() as crawler:
        for path in contact_paths:
            result = await crawler.arun(url=url + path)
            if result.success:
                if '<form' in result.html.lower():
                    # action URL・mailto:・inputフィールド名を抽出
                    return result
    return None
フルサイト解析（ドメイン→全情報一括取得）
async def analyze_site(domain: str):
    results = {
        'domain': domain,
        'contact_url': None,
        'has_form': False,
        'email': None,
        'form_fields': [],
        'cms': None,
    }
    async with AsyncWebCrawler() as crawler:
        # トップページ取得（CMS判定・全体構造把握）
        top = await crawler.arun(url=f'https://{domain}')

        # コンタクトページ探索
        for path in ['/contact', '/contact-us', '/inquiry']:
            r = await crawler.arun(url=f'https://{domain}{path}')
            if r.success and '<form' in r.html.lower():
                results['contact_url'] = f'https://{domain}{path}'
                results['has_form'] = True
                break

    return results
JSレンダリング対応（動的フォーム検出）
# React/Vue等でCSRされるフォームはJS実行が必要
result = await crawler.arun(
    url=url + '/contact',
    js_code="window.scrollTo(0, document.body.scrollHeight)",
    wait_for="css:.contact-form"   # フォーム要素が現れるまで待機
)
検出精度
検出対象精度補足
フォームURL（パス検索）◎ 高候補パスを上から順に試行・ヒット率高
<form>タグ存在確認◎ 高SSRページは即時取得可能
mailto: リンク抽出◎ 高正規表現で安定抽出
form action URL○ 中相対パスの解決が必要なケースあり
input フィールド名○ 中name属性がないフォームは取得困難
JS動的フォーム△ 低js_code + wait_for の組み合わせが必要・複雑

注意点
利用規約
スクレイピング禁止サイトへの適用は避けること（robots.txt を事前確認）
レート制限
並列リクエスト数を制限（worker=5〜10）・Jitter付き Wait を挿入してBAN回避
次のステップ
Playwright フォーム自動送信との統合 → n8n ワークフロー化 → Supabase への結果保存
