# Notion 4 DB Views セットアップガイド (Sprint 14)

> 役割: 4 DB の **Views (Board / Calendar / Gallery 等)** を Notion UI で手動追加する手順.
>       API では Views 操作不可のため、ここに記載した通り 1 つずつ作成する.
>       完成すれば「Notion 公式テンプレ並み」の営業 OS が手に入る.
>
> 前提: 4 DB の icon + cover + properties は scripts/notion-upgrade-dbs.mjs で投入済.
>       7 leads + 56 templates + sample 2 件は scripts/notion-seed-data.mjs で投入済.

## 🎯 リード DB (https://www.notion.so/8cbab1f501144f83872c1738ce3e79c4)

View タブで「+ ビューを追加」をクリックして 6 views を順番に追加:

### View 1: 📋 全リード (デフォルト・既存)
- タイプ: テーブル
- ソート: 最終更新 ↓ 降順
- 表示プロパティ: 企業名 / ドメイン / 業種 / 商談ステージ / モバイルスコア / 検出課題 / HOT / 最終更新

### View 2: 🔥 HOT leads
- タイプ: テーブル
- フィルタ: `HOTリード = ✓`
- ソート: レポート閲覧数 ↓ 降順
- 表示プロパティ: 企業名 / ドメイン / レポート閲覧数 / 📋 診断レポート / 🎬 動画レポート / 商談ステージ

### View 3: 📊 ステージ別 (カンバン)
- タイプ: ボード
- グループ化: 商談ステージ
- カードプレビュー: モバイルスコア (number)
- 表示プロパティ: 企業名 / 業種 / レポート閲覧数 / HOTリード

### View 4: 🗾 都道府県別 (カンバン)
- タイプ: ボード
- グループ化: 都道府県
- 表示プロパティ: 企業名 / 業種 / 商談ステージ

### View 5: 📅 フォローアップ予定 (カレンダー)
- タイプ: カレンダー
- 期間プロパティ: フォローアップ日
- 表示プロパティ: 企業名 / 商談ステージ / 担当者

### View 6: 🆕 今週の新規
- タイプ: テーブル
- フィルタ: `作成日時` 内 → 過去 1 週間
- ソート: 作成日時 ↓ 降順
- 表示プロパティ: 企業名 / ドメイン / 業種 / 都道府県 / 検出課題 / モバイルスコア

## 📦 納品 DB (https://www.notion.so/b3cbef9dd96f4e5bbbecc404c703a298)

### View 1: 🚧 進行中 (デフォルト)

## 📝 テンプレ DB (https://www.notion.so/115e2b0e79424bb0813fc05402096f95)

### View 1: 🎯 業種別 (デフォルト・カンバン)

- タイプ: テーブル

- ソート: 業種 ↑ / 重要度 ↓ (critical→warning→info)
- 表示プロパティ: テンプレ名 / 業種 / 課題コード / 重要度 / headline / 使用回数

### View 4: 📊 課題コード別 (カンバン)
- タイプ: ボード
- グループ化: 課題コード
- 表示プロパティ: テンプレ名 / 業種 / 重要度 / 有効

### View 5: 🔥 ホットテンプレ (使用回数 top)
- タイプ: テーブル
- フィルタ: `使用回数 > 0`
- ソート: 使用回数 ↓ 降順
- 表示プロパティ: テンプレ名 / 業種 / 課題コード / 使用回数 / 平均 CVR (%) / 最終使用日

## 🔧 追加のおすすめ設定 (Notion UI で 1 回だけ)

### 1. 4 DB を 1 つの親ページにまとめる
- 親ページ「Paradigm 営業 OS」(https://www.notion.so/35fa2b78f3fc81299d91e457889ee393)
- 親ページに `Embed database` で 4 DB を縦に並べる
- スマホ・社内共有時に 1 画面で完結

### 2. リード DB ↔ 顧客 DB の relation 双方向化
- 顧客 DB 側で「紐づくリード」プロパティを開く
- 「双方向で同期する」ON → リード DB に「紐づく顧客」プロパティが自動追加
- リードがどう成約したか追跡可能

### 3. テンプレ DB ↔ リード DB の relation 追加 (任意)
- リード DB に「使用テンプレ」(relation→テンプレ DB) プロパティ追加
- 「あの企業にはどのテンプレで送ったか」を記録
- A/B テスト用

### 4. 共有設定
- 親ページの右上「共有」→ ワークスペース全員に閲覧/編集権限
- リード DB だけは「重要顧客情報」のため一部メンバーのみ編集可
