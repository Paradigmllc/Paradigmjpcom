## 5. Plan B における優先順位

| 優先度 | 対象 | 理由 |
|---|---|---|
| **P0**（Plan B 必須・1セッション内） | nav/cta/footer/locale/chatbot/report の messages JSON 12言語 | 全 locale で UI 枠組みが破綻しない最低ラインの確保 |
| **P0**（Plan B 必須・1セッション内） | `home.services.*` `home.stats.*` `home.features.*` の messages key 追加 + HomeClient.tsx 配列を t() 経由に | トップページが 12 locale で見れる状態 |
| **P1**（Plan B 中核・別 PR） | services/page.tsx + services/{web,meo,seo,ai}/page.tsx の messages 化 | Japan Entry Package 訴求の中核 |
| **P1**（Plan B 中核・別 PR） | pricing/page.tsx の messages 化 + PPP 価格表示 | 12 locale で価格を正しく出すため必須 |
| **P2**（Plan B 補完・別 PR） | about/contact の messages 化 | CTA 動線の最適化 |
| **P3**（Plan B 範囲外） | AllInOneClient.tsx 1972行 | 提案ページは ja/en 主体・残10 locale は別 URL 設計検討 |
| **P3**（Plan B 範囲外） | lp/* ページ群 | LP は ja 主体・en は別途設計 |

**結論**: 1 セッションで P0 を完遂すれば「12-locale サイトの骨格」は完成。P1〜P3 は別 PR で段階的に messages 化していく。
