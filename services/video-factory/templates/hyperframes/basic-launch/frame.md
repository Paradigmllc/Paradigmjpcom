# Frame system

- Use the client brand tokens supplied in the brief.
- Keep all critical text within 8% safe margins.
- Never generate or redraw logos; use approved source assets.
- Prefer concise, high-contrast typography over decorative effects.
- Every composition must remain readable at 9:16, 1:1, and 16:9 or have an explicit variant-specific layout.
- Use real product UI for claims about product behavior.
